保留字体名称（Reserved Font Name）说明：
  "Source" 与 "Mona" 是上游的保留字体名称，本衍生作品
  未使用这两个名称作为字体名（本字体名为 "WDesign Sans"），符合 OFL 要求。

本字体提供的文件：
  - 7 个字重的静态 TTF / WOFF2（Thin/Light/Normal/Regular/Medium/Bold/Heavy）
  - 1 个可变字体 WOFF2（wght 250-900）
  - Web 子集（GB2312 全集 6763 字 / 一级 3755 字）

每个字体文件的 name 表 ID 0 与 ID 7 均内嵌了上述完整版权与商标声明。
