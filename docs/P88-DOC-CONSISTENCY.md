## 四、教训

### 1. 更正结论时，必须回改所有引用旧结论的地方

只写新文档是不够的。文档体系里存在「旧文档仍在被引用」的情况，
新结论必须**回填到旧文档**，否则会形成两个互相矛盾的版本。

正确做法：

```
写新文档（P86/P87）
  ↓
回改旧文档（P67）——加删除线 + 指向新文档
  ↓
更新索引（VERIFICATION-INDEX）——补入机制说明
```

### 2. 「观察属实，归因错误」是最难表达的状态

直接删掉旧结论 → 丢失了「当初观察到什么」的信息
直接保留旧结论 → 后来者被误导

**正确表达：保留观察，标注归因已更正，给出正确解释。**

这也是本项目三次自我更正（P79 / P86 / P87）的共同特征——
现象都真实存在，错的是解释。
