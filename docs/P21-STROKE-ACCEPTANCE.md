## 五、本轮方法论收获

三条测量陷阱，都已记录在案：

1. **渲染图会双向欺骗视觉**
   - 低分辨率抗锯齿：锐角看成圆角（P16）
   - 高密度锚点：平滑曲线看成折线（P20）

2. **小字号像素法不可用于形态判断**
   24px 下笔画仅 4~16 px，量化误差 100%（P19）

3. **文档里的指标可能是从宣传语照抄的、几何上不可达**
   「墨量差 ≤ 5%」物理上不可能（P18）
