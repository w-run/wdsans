## 1. 已打通：自校准减细算子

**结果**：墨密度 0.440 → **0.405**（OPPO 目标 0.368），全字库 65,524 字形，23s 处理 + 25s 保存。

**关键实现**（wds/geometry.py）：逐轮廓自校准。

```python
for seg in contours:
    a0 = abs(area(seg))
    cand = [(abs(area(offset(seg,+d))), offset(seg,+d)),
            (abs(area(offset(seg,-d))), offset(seg,-d))]
    pick = min(cand)            # 取净墨面积更小者
    out.append(pick if pick < a0 else seg)
```

**为什么必须自校准**：实测「国」需要 +5 才减墨，其余字需要 -5。
Noto 的轮廓绕向**不统一**，任何全局符号都会解错一半字形。

## 2. 三处认知纠错（都是先想错、被实测推翻的）

### 纠错 1：改 gvar delta 改不动默认实例

| 我以为 | 实际 |
|---|---|
| 缩放 delta 就是缩放笔画 | delta 是**相对 wght=400 的偏移**，只影响 400 以外的字重 |

`instancer` 重设轴后，glyf 的 base 坐标已经是 wght=400 的实际轮廓。
**要改默认实例，必须改 glyf base。** 实测：identity 与 p1 在 wght=250 完全一致（密度 0.280 = 0.280）。

### 纠错 2：等比缩放不改变墨密度

字面 ×0.985 后：密度 0.440 → **0.440**（不变），宽 848→835。

数学必然：面积与 bbox 同比缩放，比值不变。
**「字面收一圈」和「更透气」是两件事，不能互相替代。**

### 纠错 3：「出脚」不是「低于基线」

原以为 OPPO 去脚 = 字形底部不下探。实测**四个字体都下探到基线以下**：

| 字 | Noto | OPPO | HOS |
|---|---|---|---|
| 口 | -55 | **-37** | -58 |
| 国 | -80 | -80 | -78 |
| 甲 | -80 | **-108** | -71 |
| 申 | -79 | **-111** | -74 |
| 明 | -87 | **-127** | -85 |

OPPO 在「甲/申/明」上反而**下探更深**。所以 yMin 不是出脚判据。

「口」的真实底部结构（Noto，实点坐标）：

```
c0: (127,735) (877,735) (877,-51) (796,-51) (796,660) (205,660) (205,-55)
```

底横是**齐平方块**（y -51 ~ -55），没有小脚。
→ **出脚 = 部件竖起处顶端的小方突**（如「烟」左边火旁的引脚），**不是**整体底边下沉。
