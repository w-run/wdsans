# 参数定稿（基于旧版 2025.060，按 OPPO 方向修正）

参数基准 = **旧版 WDesignSans 的 7 个参数文件**（`wdsans202506/*.json`），只改已知有问题的项。
不是从 glow-sans 原始配方重来——旧版参数才是 WDesignSans 的设计意图记录。

## 改动清单

| 参数 | 旧版 | 现定 | 理由 |
|---|---|---|---|
| `feetremoval` | true | **true** | 去出脚（原本就是 true，中途误改 false 已回滚） |
| `endsremoval` | true | **true** | 去端部装饰/喇叭口 |
| `flattenends` | 1 | **0** | 1 会把所有末端斜切成 45°（复盘 §2.5） |
| `hooktension` | -0.2 | **0.475** | 负值是斜切的第二个来源 |
| `counter` | 1.048 | **0.96** | 1.048 是向外推骨架→字变大而非留白变多（复盘 §2.4） |
| `ytracking` | 1.045 | **1.0** | 同上，竖向放大 |
| `latinscale` | 1.15 | **1.00549** | cap 733/729；1.15 会到 784 |
| `raleway: N` | — | `mona: <wght>` | 拉丁换 Mona |
| `softness` | 0.85 | 0.85 | 保持（1.0 太硬，折角全直角） |
| `dotsoftness` | 0.7 | 0.7 | 保持 |
| `gravity` | 0.965 | 0.965 | 保持 |
| `xtracking` | 1.005 | 1.005 | 保持 |
| `weight` | 1.2 / 1.02 | 保持 | 保持 |
| `baseline` | 55 | 55 | 保持（需按 Mona 重新验算，待定） |
| `fontsize` | 80 | 80 | 源码里无引用，遗留字段 |

## 硬指标验收（2026-10-25）

对照思源黑原版，420px 渲染确认：

| 项 | 思源黑 | 本产物 |
|---|---|---|
| 横画末端出脚 | 有（上翘三角） | **无，矩形平收** |
| 起笔喇叭口 | 有 | **无** |
| 末端凹陷 | 有 | **无** |
| 撇捺末端 | 尖角 | **平切** |

## 字面率实测（对照 OPPO）

| 字体 | bbox_w 中位 | bbox_h 中位 | 面积占比 | w/h |
|---|---|---|---|---|
| SHS 400 | 923 | 919 | 0.845 | 1.004 |
| **OPPO 400** | **915** | **937** | **0.852** | **0.977** |
| HOS 400 | 915 | 914 | 0.833 | 1.001 |
| **本产物 (counter .96)** | **915** | **913** | **0.830** | **1.002** |

宽度已对齐 OPPO（915），高度略低（913 vs OPPO 937 —— OPPO 偏高，是它的性格）。
若全面对齐 OPPO，需要 `ytracking` 略微 >1，但会破坏「松」的目标，暂不做。
