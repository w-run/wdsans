# 拉丁字形整改计划（2026-11-20）

## 用户反馈的三个问题
```
1. 250 字重的 i/j 线条窄了太多
2. 250 字重的拉丁比中文粗了有点多
3. ōéǎì 这类带音标字母还是 SHS 字形，能否用 Mona 补齐并统一
```

## 诊断结果

### 问题1: i/j 是 SHS 字形，应为 Mona
```
原因: Mona 的 i/j 是复合字形(addComponent x2)，
      当年 m_latinext/m_latinmat 注入时用 RecordingPen 拆解失败，
      回退用了 SHS 字形。

        我们     Mona    判定
i 竖笔   36       52    =SHS (应为Mona)
j 整条   25       36    =SHS (应为Mona)
l       51       51    =Mona (正确)

全库 62 个拉丁/数字: 只有 i j 两个有问题(宽度偏差>8 or 粗细偏差>30%)
```

### 问题2: 250档 拉丁/中文 粗细比 1.52（应为 0.95）
```
250档笔画粗细(800px):
  中文 永=27 国=24 体=23    <- 与SHS完全一致(正确)
  拉丁 l=41 I=42 n=39      <- 来自Mona 250实例
  lat/cjk = 41/27 = 1.52

参考: OPPO400=0.95  SHS400=0.96  我们400=0.99

根因: Mona 字重轴 200~900(default 200)
      wght200 -> l=30 (最细也只能到30)
      而中文250 -> 永=27
      => Mona 极细档衰减慢于 SHS
```

### 问题3: 170 个带音标字母用 SHS 字形
```
带音标拉丁来源统计(318个):
  =Mona: 40
  =SHS:  170    <- 大部分
  ?:     108

关键: Mona 的带音标字母全是预组合复合字形!
  à á â ì ō ǎ é ê  -> addComponent=2, moveTo=0
  => 用 DecomposingRecordingPen 可直接拆解，无需自己合成

Mona 有 22 个组合音标 U+0300-0338，全部可用。

对比(400档):
  à Mona: 3轮廓43点 x[56,523] y[-9,735]   <- 音标在 y=735
  à 我们: 3轮廓43点 x[60,484] y[-13,822]  <- 音标在 y=822 (SHS更高)
```
