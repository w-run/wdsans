# 笔末平切 — 第二轮诊断（2026-11-19）

## 实验：端面 C->L 直接拉直的效果

凸包比（1.00=平切, >1.02=内凹）:
```
字    改前     改后     OPPO    HOS
大    1.028   1.010   1.002   1.002
人    1.031   1.009   1.002   1.001
天    1.030   1.012   1.003   1.001
夫    1.029   1.011   1.003   1.002
文    1.022   1.005   1.000   1.000
父    1.026   1.005   0.999   0.999
均值  1.027   1.009   1.002   1.001
```

**凸包比改善明显（1.027 -> 1.009），但目视出现新问题。**

## 目视发现的问题

改后「大」的捺末端出现方头/变厚，比 OPPO 明显更钝。

量化确认（沿笔画法向测末端厚度）:
```
字体          末端宽   中段宽   末端/中段
我们-改前       125      103      1.21
OPPO             98       86      1.14
HOS             119      104      1.15
```

-> 我们的捺末端本来就比参考厚 1.21 vs 1.14/1.15。
   直接 C->L 拉直会让端面变宽，问题加重。

## 更深的根因：末端位置不同，不只是段类型

我们 大（捺轮廓 y<0 部分）:
```
[0] L -> (476,504)                            上边缘
[1] C c1(551,235) c2(686,25) -> (903,-77)     下边缘长曲线
[2] C c1(916,-56) c2(941,-24) -> (960,-8)     端面（还继续外扩到 x=960）
[3] C c1(752,79) c2(616,280) -> (550,522)     上边缘回去
```

OPPO 大（单轮廓，捺末端）:
```
[8] L -> (930,507)
[9] L -> (532,507)
[12] L -> (910,-101)     <- 端面是直线，收在 (910,-101)
```

关键差异:
- 我们: 端面段一直外扩到 x=960, y=-8（向右上翘）
- OPPO: 端面收在 x=910, y=-101（向下右）
- 我们的末端在 x 方向多出 50 单位，且 y 高了 93 单位

## 结论：这不是简单的段类型问题

需要两个动作:
1. 端面段改为直线（已实验有效，凸包比 1.027->1.009）
2. 同时把末端位置收到合理处，避免端面被撑宽

或替代方案:
- 保留 C 但把 c2 控制点朝内收，让曲线在末端趋于直线
  这样段类型不变（VF 更安全），只调控制点位置

## 🔴 为什么不能全库套用

严格判据（短C+前后长段）仍命中 18,468 字 / 49,627 段 = 88%。
这正是 m_termface 走过的路（命中过宽 -> 曲线 42.3%->32.7% 灾难）。

必须做的事:
1. 先小范围验证视觉改善（本轮的 6 字实验已完成）
2. 找更精准的判据（比如同时要求末端厚度比 > 1.18）
3. 对照组必须包含 口/回/十/中/申/甲 等非撇捺字
4. 三档签名一致性校验

## 本轮产出

- 确认 C->L 能改善凸包比（1.027 -> 1.009）
- 发现直接拉直会导致末端变宽（需配合控制点/位置调整）
- 精确记录了我们的捺末端几何 vs OPPO
- 未部署（避免重演 m_termface 灾难）
