# WDesign Sans · 设计宪法

> 本文件是项目的**唯一设计权威**。任何实现、参数、验收标准与此冲突时，以本文件为准。
> 修改需在此留痕（含日期与理由），不要只改代码。
>
> 版本：v1.0 · 2026-10-22 · 状态：设计定稿，等待 P0 验证

---

## 0. 一句话定位

**一套为中文屏幕与平面大字号而做的、克制的现代人文无衬线。**

三个形容词：**干净**（clean）、**开阔**（open）、**有骨**（structured）。

明确的反面清单（**不做**）：
- 不做几何机械风（把汉字画成 Futura 那种圆规几何）
- 不做圆润可爱风（圆体、全圆角）
- 不做笔锋化的人文衬线（起收笔的喇叭口、书法味）
- 不做夸张的字重/字宽对比

## 3. 结构决策

### 3.1 单一可变字体，不拆版本

- 一个 `wdsans-vf.otf`，**SC 字形为默认**，`locl` 提供日文字形
- 不拆 `wdsans-jp`（除非 P0 验证发现 `locl` 不可行 → 二级方案）
- 理由：自用 + 嵌入开源项目，分发简单是第一优先；OpenType 本来就支持语言标记

### 3.2 字体轴

| 轴 | 范围 | 默认 | 说明 |
|---|---|---|---|
| `wght` | 250 – 900 | 400 | 只有这一根轴 |

**不做 `wdth` 轴。** 宽度系列靠"压扁轮廓"实现（glow-sans 的做法）会让字怀比例失真，那正是要避免的。需要窄体时用 CSS `font-stretch` 之外的排版手段，或后续单独做一套真正的窄体设计。

### 3.3 七个命名实例（已定稿）

| 名称 | wght | usWeightClass | 用途 |
|---|---|---|---|
| Thin | 250 | 250 | 平面大字号、极简版式 |
| Light | 300 | 300 | 大标题、浅色界面 |
| Normal | 350 | 350 | 长文正文（中文独有的"350"档，比 Regular 更耐读） |
| Regular | 400 | 400 | 界面主文本、系统字体默认 |
| Medium | 500 | 500 | 界面强调、小标题 |
| Bold | 700 | 700 | 标题、强调 |
| Heavy | 900 | 900 | 海报、大字号冲击 |

> 为什么保留 7 档：用户明确要求，且平面/网页的极简设计里极细（250）与极粗（900）是主力档位。
> 为什么有 350：中文正文在 14–16px 下，400 偏重、300 偏飘，350 是中文排版的甜点区。这一档是**中文专属需求**，不要按拉丁习惯删掉。

## 4. 视觉决策（本项目的核心，逐条可测量）

### 4.1 出角：取消装饰性出角，但**不做圆角**

| 部位 | 决策 | 数值 |
|---|---|---|
| 横画末端 | 垂直平切，允许极微斜切 | 切角 **0–6°**，禁止超过 10° |
| 竖画末端 | 水平平切 | 0° |
| 转角（横竖相接） | **直角**，仅内角做应力圆角 | 圆角半径 **0.5–1.0 unit** |
| 钩 | 短钩 | 钩长 ≤ **1.2 ×** 该笔画宽度 |
| 撇 / 捺 收笔 | **钝化**，不做针尖 | 末端宽度 ≥ **0.55 ×** 该字最大笔画宽度 |
| 点 | 保持原生形状，仅随字重缩放 | — |

**理由**：直角 + 平切 = "有骨"；全圆角会滑向可爱风；旧版的错误是 `flattenends:1` 把**所有**端点削成 45° 斜角，造成"处处缺口"的破碎感。真正的"无出角"是**不额外生出角**，不是**把角磨平**。

这一条是本项目最大的辨识度来源，也是旧版最刺眼的问题。

### 4.2 中宫：比思源黑松 4%

| 指标 | 目标 | 测量方法 |
|---|---|---|
| 字面宽 | **0.88 em**（= 880/1000） | CJK glyph bbox 宽度中位数 |
| 字面高 | **0.88 em** | bbox 高度中位数 |
| 内部负空间占比 | 思源黑 **+4%**（相对） | 轮廓填充面积 / bbox 面积，取中位数 |
| 左右/上下结构间隙 | 思源黑 **+6%** | 部件间最小距离 |

实现路径（**不是整体放大**）：部件中心向字面边缘外推 1.2–1.8%，部件自身缩 0.8%，笔画粗细不变 → 字面不变、留白增加。

**旧版的错误**：`counter:1.048 + ytracking:1.045` 是整体外推，字变大而留白没变，视觉上更挤。**"中宫宽松" ≠ "字更大"。**

### 4.3 重心：视觉重心 y = 512

| 字重段 | 视觉重心 y（基线=0，em=1000） |
|---|---|
| 250–350 | **508** |
| 400–500 | **512** |
| 700–900 | **516** |

思源黑约 504。整体抬 8 单位显得精神；粗字重视觉下坠，所以按字重递增回补。

### 4.4 宽度

全角 advance **固定 1000**，一个不动。所有"宽/窄"的感觉都由字面率与内部间隙产生，不由 advance 产生。这样中文网格在任何排版引擎里都不会错乱。

## 5. 拉丁：Mona Sans 二次开发

| 项 | 决策 | 理由 |
|---|---|---|
| cap height | **733**（与思源中文一致） | 混排时拉丁不"跳出来" |
| x-height | **529**（= Mona 原值 × 1.0055，**不拉齐到思源的 543**） | Mona 的小 x-height 是它的性格；配合开阔的中文更透气。这是**裁断**，若视觉 QA 失衡再统一 ×1.02 |
| 基线 | 0（与中文同基线） | — |
| typo 上/下伸 | **880 / -120**（沿用思源，**不用 Mona 的 1090/-320**） | Mona 的垂直度量会把行高撑爆 |
| 数字 | 默认比例宽度；`tnum` 提供等宽 | 界面里表格需要 |
| 斜体 | **不做** | 中文无真斜体，混排时不协调；需要斜体时用其他字体族 |

**旧版的错误**：cap 被放到 784（比中文高 51 单位），样张里拉丁永远压过中文；且 7 档参数里写着 `raleway`，说明参数表与产物已经脱节。

## 6. 语言与符号

| 项 | 决策 |
|---|---|
| 简体中文 | 主字形，默认 |
| 日文 | `locl` 切换（同一文件）；「直/骨/次/令」等差异字必须能正确切换 |
| 繁体 | 不做（保持 SC 默认字形，`locl` 未来可扩展） |
| 韩文 | **不做** |
| 拉丁扩展（希腊/西里尔） | 保留思源自带 |
| 颜文字/符号 | **cmap 一个码位都不删**。U+3000 区、U+FF00 区、箭头、数学、制表符、假名全覆盖 |

> **铁律：任何构建步骤都不得删除 cmap 条目。** 删掉一个码位，在任何场景下都会变成豆腐块。这一条是旧版的直接教训（`delete cmap[cid]`）。

## 7. 排版度量

```
unitsPerEm           1000
typoAscender          880
typoDescender        -120
typoLineGap            0
winAscent            1160
winDescent            288
hhea ascent          1160
hhea descent         -288
hhea lineGap            0
underlinePosition     -120
underlineThickness    见字重（≈ 竖画的 85%）
```

> 默认行高 = 1000/1000 = 1.0 em，给排版留出自行调节的空间，不内置夸张行距。

## 8. 非目标（明确不做，防止范围蔓延）

- 韩文、CJK 扩展 G/H 区
- 真正的窄体/宽体轴
- 圆体、手写体、书法体
- 斜体（italic）
- 装饰性连字、风格集（`ss01+`）——不新增，但**保留思源已有的**
- Emoji（交给系统 emoji 字体）
