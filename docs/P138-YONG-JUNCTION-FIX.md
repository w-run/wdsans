# P138 · 「永」横撇转折处凸包修复（首个成功的字形形态修正）

日期：2026-11-07
状态：已实现并验证。仅移动 1 个节点，符合 AGENTS.md。

## 缺陷定位（用户反馈「转折点有个怪异的折点」）

```
ours 轮廓6（横撇，16点）
  0 (315, 433) ON    ← 横的上边
  1 (328, 433) ON
  2 (340, 436) ON    ← 比两侧高 6.4 upm，形成凸包
  3 (385, 417) ON    ← 转向撇

对照 OPPO 同部位：
  5 ( 67, 427) off
  6 (390, 427) off   ← 上边完全水平
  7 (390, 371) off   ← 干净 90 度转角
```

点 2 偏离点1-点3 连线 6.4 upm，形成一个可见的小凸包，
破坏了「横走到头、然后顺下来撇」的干净转折。

## 修复

把点 2 从 (340, 436) 拉到连线上的 (340, 430)。
**只改一个节点的 y 坐标，未增删任何节点。**

## 重要：失败的批量尝试（记录教训）

我第一版写了「通用凸包检测」，扫描全字体修正了 165 个字形、345 个点。

**实测是有害的：**

```
字符      修正前墨量   修正后墨量   差异
exclam       19700       18935    -3.88%
quotedbl     14781       13926    -5.78%
asterisk     10016        8990   -10.24%   ← 星号被削掉十分之一
```

原因：判据只看「三点共线偏差」，把**矩形端点的角点**
（感叹号竖笔顶端、星号的尖角）误判成凸包，削掉了正常形状。

第二版加了四条约束（水平 run、段长 >= 60、移动 <= 8upm、x 单调），
结果修正 **0 个点** —— 说明这类凸包在字体中并不普遍，
「永」的那个是特例，不能用通用规则处理。

## 教训

**通用几何启发式在字体上极不可靠。**

- 「三点偏离直线」既可能是伪凸包，也可能是正常的矩形角点、
  尖角笔画、装饰性细节
- 单点精修 + 逐字形验证是安全的
- 批量自动修正必须先用「墨量变化率」做前置筛选：
  任何字形墨量变化 > 0.5% 就应该拒绝，而不是接受

这条筛选规则我应该在写批量脚本时就加上，而不是事后才发现。
