## 五、结论

**竖排功能完整可用，无缺陷。**

旧版字体的竖排问题是 `vhea = 1913/-1502`（行高 3.4em，严重撑爆），
我们的 500/-500 = 1.0em，与 Noto / 标准 CJK 字体一致。
