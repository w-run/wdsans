## 本版修复的两个用户需求

### 需求：闭口偏旁垂直居中 + 拉高
原描述：「口日田目这些部首在需要调整视觉调整的同时应该再拉高一些」
        「相对于右侧主体」居中
```
根因: 不是位置偏，是偏旁被压扁了
  叫  我们 y[167,745] 高578  SHS y[ 79,749] 高670
      顶差 -4   底差 +88
  昨  我们 y[111,766] 高655  SHS y[ 30,762] 高732
      顶差 +4   底差 +81
  -> 顶边几乎不动，底边需下移 79~97（中位 80）

修法: 顶边固定，底边下移 80（400档基准，按字重等比缩放）
规模: 1,040 字（IDS 筛出 1,075，实际命中 1,040）
验证: 17/17 匹配 SHS，误差 ±22 单位
  叫 h658 c416 / SHS h670 c414
  昨 h735 c400 / h732 c396
  晴 h734 c406 / h735 c404
```

### 需求：左偏旁底部出脚
原描述：「都」左下的日字形底部右侧出脚还在、没被去掉
```
都 400档: c6 LLLLLL x[147,471] y[-16,374]  「日」外框
         c7 LLL    x[442,514] y[-60,374]  「日」右竖，底低 44
修法: 竖条下端 -> 方框底缘
规模: 11 字（僘厥塑嵞朔槊磊蒴都鬬鬭）
效果: 都的出脚 250档 52->0 / 400档 44->0 / 900档 34->0
```

## 未实现项（诚实说明）

**横折出头**（顶部横笔右端延伸）
三轮自动判据（几何轮廓法）均误伤左侧偏旁的横笔，最大一次误伤
1,456 / 20,992 字，已放弃自动方案。当前继承思源黑体的原始形态。
若重做需建立部件级分割，或改为逐字白名单。

**横折撇偏粗**（多、及、予 等）
实测 250 档撇厚 38 vs SHS 28（+10 单位 ≈ 1% em，正文与海报字号不可见）。
根因是 m_barple 把横笔右端拉到 770 而 SHS 只到 722（「拐角竖直」的固有代价）。
事后补丁判据无法区分「多」与「水」，重建链实测反而让 900 档恶化 10 单位。
该方向已证伪并记录，不再投入。
