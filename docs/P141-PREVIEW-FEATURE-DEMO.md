## 教训

**交付物说明必须与实际状态同步更新。**

「无 tnum」这条声明从 v7 一直错到 v13 —— 中间 tnum 已经
修好并验证过了（P127），但页脚没人改。用户看到这句话会
以为特性没做，直接误判整个项目的完成度。

每完成一项功能，应该同步检查：README / 预览页 / 文档索引
三处是否都反映了新状态。
