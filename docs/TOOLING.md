# 工具链（稳定版）

> 目标：**先保证预览可信，再谈改字**。
> 版本：v1.0 · 2026-10-23 · 替换掉之前所有临时脚本

---

## 为什么重做

之前的预览用浏览器 `@font-face` 加载子集字体。子集里少了测试字时，
浏览器会**静默回退到系统字体（PingFang）**，四列字全变成同一个字体，
页面上完全看不出来——由此得出了多个错误结论（包括"旧版更轻"这个反了 13% 的判断）。

新方案：**字体轮廓 → SVG → PNG（rsvg-convert）**。
路径数据直接来自字体，不经过字体加载，不存在回退。

---

## 固定画框（所有工具共用，不可随意改）

```
em 坐标（1000 upm）
  x ∈ [-20, 1020]      宽 1040
  y ∈ [900, -140]      高 1040
  → 正方形，基线 y=0 距顶部 900
  → 8×8 网格，每格 130 单位
  → 列 a–h（左→右），行 1–8（上→下）
```

**任何字体、任何字形都用这一套画框**，所以 `d2` 在所有图里指的是同一块物理区域。

## 三个工具

### 1. `glyph_view.py` — 单字形预览

```bash
# 整字 + 网格
python3 glyph_view.py --font shs350.otf --glyph 永 --out 永.png --grid

# 只看 d2 到 f3 这一块
python3 glyph_view.py --font shs350.otf --glyph 永 --out 永_d2f3.png --crop d2-f3 --grid

# 导出 SVG（可直接看坐标）
python3 glyph_view.py --font shs350.otf --glyph 永 --out 永.svg --svg
```

### 2. `glyph_suite.py` — 批量单字形

**每字体 × 每字形 → 一张独立 1024px 图**，并生成逐格墨水占比索引。

```bash
python3 glyph_suite.py \
  --fonts "shs=思源350=/tmp/p0/shs350.otf,o=OPPO=/tmp/p0/oppo.ttf" \
  --glyphs 永国回 \
  --outdir /var/minis/workspace/preview/A
```

产出：

```
A/shs_永.png          整字 + 网格
A/shs_永_index.txt    每格墨水占比
```

索引长这样，用来**定位细节在第几格**：

```
a1=0.00  b1=0.00  c1=0.27  d1=0.26 ...
a2=0.00  b2=0.00  c2=0.02  d2=0.27 ...
```

对比两个字体的索引，**数值差得最多的格子就是差异所在**，
然后 `--crop` 到那一块，就能精确放大。

### 3. `hb_render.py` — HarfBuzz 渲染（校验用）

`hb-view` 直接读字体文件渲染。用于**交叉验证**：如果 SVG 渲染和 hb-view 渲染
在墨占比上差很多，说明有一边出了问题。

```bash
python3 hb_render.py --out x.png --glyph 永 --size 640 \
  --fonts "s=思源350=/tmp/p0/shs350.otf,o=OPPO=/tmp/p0/oppo.ttf"
```

它会打印每格图的 `ratio`（墨占比）与 `bbox`，**出现 None 就是该字体缺字或加载失败**。

## 工作流程（推荐）

1. `glyph_suite.py` 批量出图 + 索引
2. 打开 `*_index.txt`，比较两个字体**同一格**的数值
3. 挑差值最大的 2–3 格，用 `glyph_view.py --crop` 放大
4. 看图确认差异性质（是端点？是粗细？是位置？）
5. 改算子 → 重跑 1

> 这条链路的意义：**先用数字定位，再用眼睛判断**。
> 反过来（先扫全字再看）会漏掉局部差异，因为整字缩略图里 10 个单位的差别看不出来。

## 已知限制

- `rsvg-convert` 环境没有 fontconfig，SVG 里的 `<text>` 会变成豆腐块，
  所以格号是渲染后用 PIL 叠上去的（PIL 用内置位图字体）。
- 画框是 1040 单位见方，**超出 -20..1020 / -140..900 的部分会被裁掉**。
  汉字一般不会超出，但生僻字可能会有，届时改 `X0/X1/Y_TOP/Y_BOT` 常量即可。
- 所有工具都要求字体里真的有这个字形，缺字会直接报错，**不会静默替换**。
