## 本轮阻碍：大文件保存反复失败

```
现象: 改字形后 f.save() 无输出、无报错、进程静默消失
      （文件不生成），但同样的字体不改直接 save 只需 200 秒成功。

测试记录:
  不改直接 save (38.4MB)          -> 成功 200s
  改 1 字后 save                  -> 卡住
  改 100 字后 save                -> 卡住
  改 1040 字后 save               -> 卡住
  改 7646 字后 save (fix_r41_b)   -> 成功（那次从已改版出发）

推测: 不是数量问题，而是「从已改版再改」时 CFF2 编译进入异常路径。
      下次应用「每次改动都从原始基座重新做」，不要增量叠加。
```
