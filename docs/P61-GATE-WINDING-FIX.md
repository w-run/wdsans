# P61：修复闸门的绕向盲区

## 起因

P60 发现 `AreaPen` 的有向面积受**轮廓绕向**影响。
顺着这条线索检查代码库，发现四道闸门里的 `geo_gate` 用了同样的写法。

## 一、先分清两种用法

代码库里有两种 `AreaPen` 用法，**只有一种有风险**：

| 用法 | 位置 | 是否受绕向影响 |
|---|---|---|
| 算**单个轮廓**面积 | `thinning.py:_area(seg)` | **不受**（单轮廓无内孔）|
| 算**整个字形**面积 | `geo_gate.py`、`gates.py` | **受影响** |

`thinning.py` 的 `_area` 逐段算多边形面积，用于「减细后面积是否变小」的判断，
每个 seg 是独立轮廓，不存在内外抵消，**逻辑正确，不需改**。

## 二、量化风险

扫描全库，对比两种度量：
```
A = 有向面积和（现有用法）
B = 各轮廓 |面积| 之和（正确墨量）
```

找 `A << B` 的字形：

```
扫描 65535 字形
发现 816 个字形存在绕向抵消
```

| 字形 | A（有向）| B（绝对和）| A/B |
|---|---|---|---|
| `.notdef` | 276712 | 1288280 | **0.215** |
| `copyright` | 150187 | 759229 | **0.198** |
| `registered` | 79768 | 353614 | 0.226 |
| `O` | 159234 | 551702 | 0.289 |
| `o` | 104176 | 280738 | 0.371 |
| `zero` | 139401 | 394320 | 0.354 |
| `degree` | 48222 | 97625 | 0.494 |

**816 个字形的有向面积只有真实墨量的 20%~49%。**

## 三、当前会不会误判

`geo_gate` 的判据是 `area < 200` 才算「极小碎片」。

上表这些字形的有向面积都远超 200（最小 48222），**所以当前不会误判**。

### 但这是潜在盲区

构造一个反例：
```
外轮廓面积 210，内轮廓 205，且同向  →  有向和 = 415（通过）
外轮廓面积 210，内轮廓 205，且反向  →  有向和 = 5  （误报！）
```

**同一个字形，只因绕向不同，判定结果完全相反。**
作为闸门，这个判据是不可靠的。

## 四、修复

把 `abs(AreaPen 总和)` 换成**逐轮廓 |面积| 求和**：

```python
def _contour_abs_areas(glyph_set, name):
    """返回该字形每个轮廓的 |面积| 之和（绕向无关）。"""
    rec = RecordingPen()
    glyph_set[name].draw(rec)
    total = 0.0
    pen = None
    for op, args in rec.value:
        if op == "moveTo":
            if pen is not None:
                total += abs(pen.value)   # ← 每个轮廓分别取绝对值
            pen = AreaPen()
            pen.moveTo(args[0])
        # ... lineTo / curveTo / qCurveTo / closePath
    if pen is not None:
        total += abs(pen.value)
    return total
```

### 关键差别

| 方式 | 对「外 210 + 内 205 反向」| 对「外 210 + 内 205 同向」|
|---|---|---|
| 旧：`abs(总和)` | 5（误报碎片）| 415（正常）|
| **新：`Σ\|各轮廓\|`** | **415（正常）** | **415（正常）** |

**新方法对绕向完全免疫。**

## 五、验证

修复后重跑：
```
检查: WDesignSansSC-Regular.ttf
  极小碎片: 0
  意外零面积: 0
几何健壮性: 通过
```

**结论与修复前一致**（都是 0 个问题），
说明本字体本来就没有碎片——但闸门现在**在对的情况下通过**，不是靠运气。

## 六、结论

| 项 | 结果 |
|---|---|
| 受影响闸门 | `geo_gate.py`（已修）|
| 不受影响 | `thinning.py`（单轮廓，逻辑正确）|
| `gates.py` G1 | 判据 `abs(pen.value) < 1.0`，1.0 极小，恰在边界——但只用于找「面积<1」，绕向抵消需内外几乎相等才会触发，实际风险低（见下）|
| 绕向抵消字形 | 816 个，但都远大于阈值 |
| 修复后结果 | 不变（0 问题），但判据现在可靠 |

### 关于 gates.py G1

它的判据是 `abs(pen.value) < 1.0`（比 geo_gate 的 200 严格得多）。
要误判必须内外轮廓面积差 < 1，这在实践中几乎不可能
（要么真空白，要么内外差异远大于 1）。

**保留现状**，但在文档里记录这个已知的度量特性。

## 七、教训

**发现一个工具缺陷后，要立刻搜整个代码库有没有同样的用法。**

P60 我花了一轮才搞明白 `AreaPen` 的问题，
如果就此收工，`geo_gate` 里同样的隐患会一直留着——
今天没暴露，只是因为恰好没有「内外面积接近且同向」的字形。

**缺陷不会只出现在你发现它的那一个地方。**
