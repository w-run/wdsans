# P84：笔画收尖形态（P83 遗留观察的定性）

## 承接 P83

P83 看图时注意到「我们的点拨比 OPPO 略钝」，
但当时只有单字观察，按自己定的规矩**不下结论**。

本轮扩到 9 个字、三方对照（数据 + 视觉），给出定性。

## 一、先测笔画宽度（排除一个可能）

含点画的 9 个字（永小少心必犬太主文六），400px 渲染：

| 字体 | 平均笔画宽 | 最大笔画宽 |
|---|---|---|
| **我们** | **22.4** | 35.9 |
| Noto | 26.6 | 42.0 |
| OPPO | 23.4 | 36.2 |
| 鸿蒙 | 28.2 | 43.4 |

### 发现

| 对比 | 差值 |
|---|---|
| 我们 vs Noto | **−16%**（更细）|
| 我们 vs OPPO | **−4%**（很接近）|

我们与 OPPO 的笔画粗细非常接近（22.4 vs 23.4），
但视觉上我们的末端更钝——**说明「钝」不是粗细问题**。

## 二、再测收尖比（真正的指标）

定义：`p20宽 / p95宽`。值越小 → 末端越细 → 越尖。

| 字体 | 收尖比 | 排名（越尖越前）|
|---|---|---|
| Noto | **0.211** | 1 最尖 |
| 鸿蒙 | 0.212 | 2 |
| OPPO | 0.221 | 3 |
| **我们** | **0.230** | **4 最钝** |

### 逐字数据高度一致

```
我们   0.23 0.22 0.22 0.23 0.23 0.23 0.23 0.23 0.23 0.23
Noto   0.21 0.20 0.21 0.21 0.20 0.23 0.23 0.20 0.21 0.20
OPPO   0.22 0.22 0.22 0.22 0.22 0.22 0.22 0.23 0.22 0.22
```

**我们 9/9 个字都是 0.22–0.23，几乎没有波动**——这是系统性特征，不是个别现象。

## 三、视觉确认

图：docs/img/p84-taper.png（「小必太主」三款字体，200px 放大 3 倍）

肉眼观察：

1. **「小」的左撇**：我们的末端偏方、平切；Noto 更尖
2. **「必」的点钩**：我们收尾较钝；OPPO 收得更细
3. **「太」的撇捺**：我们末端略平；Noto 略尖锐
4. 整体观感：我们比 Noto **略「硬」**，但比 OPPO 差别不大

**视觉与数据（0.230 最高）方向一致。**

## 四、根因：减细的法向平移必然钝化末端

减细的做法是「把每个节点沿法向向内平移固定距离」（横 −12 / 竖 −7 upm，P52）。

```
笔画末端原本是一个尖角（两条边交汇于一点）。

沿法向平移后：
  两条边各自向内移动
  但交汇点要重新求交 → 得到一个新的、更宽的平切面
```

几何上：**固定距离法向内缩，会让尖角变成圆角或平角**。
这是偏移（offset）操作的固有性质。

### 与 P53 同源

P53 发现「减细是固定偏移，不是比例缩放，导致粗细档非线性」。

本轮发现的是**同一个机制在另一个维度上的表现**：

| 维度 | 表现 | 出处 |
|---|---|---|
| 粗细 | 固定偏移导致档位增量不均匀 | P53 |
| 端点形态 | 固定偏移导致尖角钝化 | **本轮** |

## 五、是否缺陷

| 判断依据 | 结论 |
|---|---|
| 幅度 | 收尖比 0.230 vs Noto 0.211，**差 0.019（9%）** |
| 视觉 | 放大 3 倍可见，实际字号下**不明显** |
| 一致性 | 9/9 字统一，**不是随机瑕疵** |
| 来源 | 减细的必然结果，**不是错误实现** |
| 与 OPPO 比 | 0.230 vs 0.221，**差 0.009（4%）**，接近 |

### 结论：**设计取舍，非缺陷**

理由：

1. 减细本身是**有意的设计**（P52-P54），钝化是它的连带效果
2. 幅度小（vs Noto 9%，vs OPPO 4%）
3. 与 OPPO 的差距在可接受范围——OPPO 也是「简约」路线
4. 若要修（恢复尖角），需要重新求交并可能改点数量，**违反「不增删节点」铁律**

## 六、这条记录的价值

### 1. P83 的「不下结论」是对的

P83 我注意到差异但只有单字观察，明确写了「留待样本充足再判断」。

本轮扩到 9 个字后，结论是：

- 差异**真实存在**（不是错觉）
- 但**幅度可量化（0.019）、来源明确（减细）、一致性高**
- 因此是设计取舍，不是缺陷

**如果 P83 当时就说「我们的点画有缺陷」，那是错的。**

### 2. 一个机制会在多个维度留下痕迹

「固定距离法向偏移」这个机制，目前已知在两个维度留下影响：

| 维度 | 影响 | 是否已定性 |
|---|---|---|
| 粗细档增量 | 非线性（+5/+20/+8/+21/+27）| P53，正常 |
| 端点收尖 | 钝化 9% | **本轮，正常** |
| 重心 | 略低 0.69% em | P75，正常 |
| 档位间重心漂移 | 跨度比 Noto 小 19% | P76，反而更优 |

**同一条设计决策，带来了 1 个优点、3 个可量化的小偏差，全部可接受。**

### 3. 「钝」这件事本身可能不是坏事

注意：我们比 Noto 钝，但 Noto 是**最尖**的一档（0.211）。

OPPO（0.221）和鸿蒙（0.212）之间也有差异。

**收尖程度没有绝对的「正确值」**——它是字体气质的一部分。

偏钝给人感觉更**稳重、现代**；偏尖更**传统、锐利**。
我们定位「简约干净」，偏钝是符合定位的。
