# 从零分析：能向鸿蒙与 OPPO 学什么

> 2026-10-23 · 不看旧结论，全部重量
> 工具：`metrics.py`（整体）、`profile.py`（布白剖面）、`detail.py`（单笔）、`montage.py`（对照图）

---

## 一、方法

按**结构类型**分组取样，每组 2–10 字，覆盖骨架差异最敏感的形状：

| 组 | 样本 |
|---|---|
| 独体 | 永木水火大小人心力女 |
| 上下 | 雪思花字京泉 |
| 左右 | 明林特到江部 |
| 包围 | 国回田同门图园 |
| 半包围 | 这建延局原 |
| 复杂 | 赢藏攀囊 |
| 极简 | 一二十丁厂 |
| 钩折 | 手寸事丁也己 |

三家都取 400 档（鸿蒙、OPPO、思源标称同一档，实际粗细差很多，见后）。

---

## 二、第一结论：骨架比例是一样的

先测最容易"以为有差异"的地方 —— 部件分界位置（上下结构的分界行、左右结构的分界列）：

| 字 | shs | hos | ops |
|---|---|---|---|
| 京 | 4/16 | 4/16 | 4/16 |
| 雪 | 8/16 | 8/16 | 8/16 |
| 思 | 9/16 | 9/16 | 9/16 |
| 花 | 5/16 | 5/16 | 5/16 |
| 明 | 7/16 | 7/16 | 7/16 |
| 江 | 5/16 | 5/16 | 5/16 |

**几乎完全一致。** 汉字的结构比例是几百年的共识，不是可以"创新"的地方。
所以差异只可能落在三个层面：**字面大小、笔画重量、笔画形状**。

后面的分析全部按这三层展开。

**读出来的三句话：**

1. **思源"外框撑满"**：包围 0.724、钩折 0.827 都是三家最大。

3. **鸿蒙"三项都略小、笔画最重"**：字面普遍最低（0.686–0.825），
   但笔画最粗（80/77），所以**黑度最高**。

## 四、从鸿蒙能汲取的三条

### ① 笔画总量 +7%，但字面不放大 —— 单位黑度最高

```
竖/横：hos 80/77   shs 75/71   ops 66/64
字面：hos 0.792    shs 0.803   ops 0.806
```

鸿蒙是**唯一"笔画更粗、字面反而更小"**的。结果是同等字号下它的字心最实、
小字号最清楚。OPPO 相反：字面最大、笔画最细，13px 就开始发灰。

**落地**：目标竖笔 78±2（比思源高 4%），同时字面不得低于 0.79。
**风险**：加大笔画会让字变钝，必须靠撇捺收分补回笔势（见 OPPO 第 ③ 条）。

### ② 左右结构墨量几乎相等

```
左右结构 lr（左半墨量/右半墨量）：
hos 0.998   ops 1.025   shs 0.937   wdo 0.930
```

思源的左右结构右半比左半重 6.7%（`lr 0.937`），鸿蒙几乎正好 1.0。
这决定了整段文字看起来"正不正"。思源偏右重是它显得略"漂"的原因之一。

**落地**：左右结构生成的最后一步校验 `lr ∈ [0.96, 1.04]`，超出就调部件宽度。

### ③ 出脚比思源更明显，且仍按复杂度递减

```
口：hos +93/+88   shs +85/+81   ops 0/0
日：hos +68/+67   shs +65/+60   ops 0/0
国：hos +56/+57   shs +51/+51   ops 0/0
```

鸿蒙把思源的"竖画出头"又加重了约 10%，同时保留了"越复杂越收敛"的规律
（口 93 → 日 68 → 国 56）。这是传统黑体最容易被识别的手写感。

**落地**：出脚取 90±5（口），并按 `口 > 日 > 回 > 国` 递减，比例照鸿蒙。

## 五、从 OPPO 能汲取的三条

### ① 包围结构适度收框 —— 给行间留呼吸

```
包围字面：shs 0.724   hos 0.686   ops 0.668
```

OPPO 把 `国回田同门图` 这类框子收小 8%。密排时框与框之间不会蹭在一起，
这是它"看起来透气"的第一原因，不是笔画细。

![国字叠图](img/overlay-guo.png)

红线（思源）外框最外，绿线（OPPO）最内，底部还整体低一截 —— 收框是实测的，不是观感。

**落地**：包围类目标字面 0.68±0.02。但**不能像 OPPO 收得那么彻底**——
它收到的代价是单字显得小、与开放结构的字并排时不齐。

### ② 中宫更空

```
独体留白：ops 0.784   shs 0.763
中央 4×4 格墨量：ops 0.127   shs 0.141   wdo 0.147
```

思源的中宫偏满（0.141），OPPO 最空（0.127）。中宫空 = 内部透气，
但也意味着笔画离得远、字显得散。

**落地**：中宫目标 0.128–0.132（取两者之间偏空）。不取 0.127 的下限，
因为再空就需要更多笔画宽度去撑，会和第 ① 条冲突。

### ③ 曲线连续，但要偷它的"形状"不要偷它的"节点预算"

```
独体曲线占比：ops 0.734   hos 0.624   shs 0.598
独体节点数：  ops 36.0    hos 26.8    shs 20.8
```

OPPO 的弧线确实顺 —— `人`、`水`、`木` 的撇捺过渡没有"折点感"，
代价是节点数接近思源的 1.7 倍。这是**用数据量换圆润**。

**落地**：曲线占比目标 0.50–0.60（介于思源 0.37 与 OPPO 0.55 之间偏 OPPO），
但**节点硬上限 45/字**。也就是说：要学会 OPPO 的过渡方式，用思源的节点预算做出来。
如果做不到，宁可降到 0.45，也不要为圆润付节点。

## 六、明确不汲取的

**鸿蒙**

| 问题 | 数据 | 为什么不学 |
|---|---|---|
| 行距过大 | typo 1056/−271（思源 880/−120） | 同一 font-size 下，鸿蒙的行高比思源大 20%，混排会错行 |
| 低字重不成比例 | 250 档竖笔 27，400 档 83 | 从 250 到 400 涨了 3 倍，曲线非线性，无法按比例外推 |

**OPPO**

| 问题 | 数据 | 为什么不学 |
|---|---|---|
| 400 档过细 | 竖 66（思源 75，−12%） | 小字号发灰，正文不扛印 |
| 节点过多 | 61/字（思源 42） | 13px 以下会糊成一团 |
| 无出脚 | 包围全部 0 | 丢掉了传统黑体最强的识别特征 |

**旧版（作为反例）**：笔画照抄思源（76/72 ≈ 75/71）、字面却缩到 0.777，
且 cap 被拉到 784 —— **改了一半，两头不匹配**。

## 七、合成后的 WDesign Sans 目标参数

| 项 | 目标 | 来源 | 理由 |
|---|---|---|---|
| 竖笔 | 78 ± 2 | 鸿蒙 80 / 思源 75 | 取中去 4%，正文更清晰 |
| 横笔 | 73 ± 2 | 同比例 | 保持 H/V ≈ 1.065 |
| H/V 反差 | 1.06–1.07 | 思源 1.068 | 比 OPPO 的 1.027 更有竖势 |
| 字面（整体） | 0.80 ± 0.01 | 思源 0.803 / OPPO 0.806 | 不低于思源 |
| 字面（包围） | 0.68 ± 0.02 | OPPO 0.668 | 收框换行间呼吸 |
| 中宫 core | 0.128–0.132 | OPPO 0.127 / 思源 0.141 | 偏空但不散 |
| 曲线占比 | 0.50–0.60 | OPPO 0.55 / 思源 0.37 | 取 OPPO 的过渡 |
| 节点/字 | ≤ 45 | 思源 42 | **硬上限**，不能为圆润突破 |
| 出脚（口） | 90 ± 5 | 鸿蒙 93 / 思源 85 | 取鸿蒙 |
| 出脚递减 | 口 > 日 > 回 > 国 | 三家一致 | 保持视觉补偿规律 |
| 撇捺收分比 | ≥ 1.4 | 思源 1.5 / OPPO 1.4 | 笔画加粗后要收锋补势 |
| 左右平衡 lr | 0.96–1.04 | 鸿蒙 0.998 | 整段不歪 |
| cap | 733 | 思源 | 不得回到 784 |
| 垂直度量 | 880 / −120 | 思源 | 不用鸿蒙的 1056/−271 |

**一句话概括取舍**：
> 用鸿蒙的**重量与均衡**，用 OPPO 的**收框与弧线**，
> 但弧线必须用思源的**节点预算**实现 —— 这是三条里唯一真正有难度的一条。
