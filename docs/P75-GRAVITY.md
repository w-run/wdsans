# P75：汉字重心（视觉中心）测量

## 为什么查这个

前面几轮都在做工程质量（闸门、路径、命名），本轮回到字体本身。

**重心（视觉中心）是 CJK 字体观感的关键指标**：

| 重心位置 | 观感 |
|---|---|
| 偏高 | 字「飘」，行看起来松散 |
| 偏低 | 字「闷」，行看起来压抑 |
| 适中 | 稳定、易读 |

此前从未量化过。

## 一、测量方法（第一次：点采样，有缺陷）

最初用「字形所有控制点坐标的均值」当重心：

```
我们 Regular   312.6   σ=293.8   928 点
Noto 400       311.0   σ=296.4   928 点
OPPO 400       331.3   σ=281.0   907 点
鸿蒙 400       343.0   σ=283.2   744 点
```

**这个方法的缺陷**：控制点分布取决于曲线复杂度，
不是墨迹分布。曲线密集的字（如「永」）被过度加权。

而且 σ 接近 300（几乎等于字高），说明点分布极度分散，均值意义有限。

## 二、改用渲染像素（墨量加权质心）

正确做法：渲染 400px，按**每行实际墨量**加权求质心。

| 我 | 179.3 | 181.8 | 180.8 | 177.7 |
| 日 | 168.5 | 174.9 | 164.6 | 173.9 |

## 三、发现：重心系统性偏低 2.8 px

```
我们         175.3
Noto         178.0   (差 -2.7)
OPPO         177.5   (差 -2.2)
鸿蒙         178.7   (差 -3.4)
三参照平均   178.1   (差 -2.8)
```

### 关键：这是系统性偏差，不是随机

| 对比 | 偏低字数 |
|---|---|
| vs 三参照均值 | **9 / 10** |
| vs Noto | 6 / 10 |

**10 个字里 9 个都偏低**——这是规律，不是测量噪声。

### 为什么会偏低

这与 P52/P53 的减细机制同源：

- 减细做法向平移（横 −12 / 竖 −7 upm）
- 字的下半部分（横画密集处）比上部（撇捺多）受影响不同
- 净效果：墨量重心略微下移

相当于「下半部分减得更少」→ 重心相对下沉。

## 四、换算：亚像素级，不可见

```
400px 渲染下差 2.8 px
比例 = 2.8 / 400 = 0.69% em

12px 字号 → 0.08 px
16px 字号 → 0.11 px
24px 字号 → 0.17 px
48px 字号 → 0.33 px
```

**任何实际字号下都远小于 1 像素。**

## 五、视觉确认

图：docs/img/p75-gravity.png（四款字体同排「中国永和九年天地」，红线为基线）

肉眼观察：
1. **四行的字都稳坐在基线上**，没有上浮或下沉
2. **重心差异肉眼不可辨**
3. 我们的字看起来比 OPPO/鸿蒙略「轻」（这是减细造成的，P52 已知）

## 六、结论

| 项 | 结果 |
|---|---|
| 平均重心 | 175.3（三参照 178.1）|
| 偏差 | **−2.8 px / 400px = 0.69% em** |
| 系统性 | **9/10 字偏低**，是规律 |
| 16px 下实际差 | **0.11 px** |
| 可见性 | **不可见** |
| 是否缺陷 | **否**，是减细的连带效果 |

## 七、教训

### 1. 质心计算不能用控制点，要用墨量

第一次用「控制点均值」，σ=294（几乎等于字高），完全失去意义。

因为控制点数量取决于**曲线复杂度**，不是墨迹多少：
- 一个圆弧可能只有 3 个点，但覆盖大片面积
- 密集小笔画可能有 20 个点，墨量却很少

**要测「墨量的分布」，就必须按墨量加权。**

这是 METHOD-TRAPS 里「度量要选对口径」的又一次。

### 2.「系统性偏低」比「数值有差」更重要

单个字差 2.7，可能是测量噪声。
但 **9/10 字都偏低**，就说明存在真实的结构性原因。

**判断是否为真问题时，看「方向一致性」比看「差值大小」更有意义。**

### 3. 找到原因后，还要判断「是否需要修」

重心偏低是减细的连带效果——而减细是**有意的设计**（P52-P54）。

如果为了「重心与 Noto 一致」而去调整，会破坏减细带来的视觉平衡。

**偏差可量化（0.69% em）、不可见（0.11px）、有明确来源（减细）**——
这三个条件同时满足，就是「记录但不修」。
