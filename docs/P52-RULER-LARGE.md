# P52：大字号标尺测量（笔画厚度与字面尺度）

## 方法

目标要求「细节用标尺」。此前测量多在 20-32px 小字号做
（受 hinting 与像素栅格影响）。本轮用 **320px 大字号**，
1 单位 ≈ 0.32px，测量精度足够反映真实笔画。

文字：国（有外框，可测字面与壁厚）、一（纯横画，可测厚度）、永（复合）。

## 一、横画厚度（一，320px 渲染）

| 字体 | 厚度 px | 换算成 upm (÷0.32) |
|---|---|---|
| **我们** | **23** | **72** |
| OPPO | 22 | 69 |
| Noto | 26 | 81 |
| 鸿蒙 | 27 | 84 |

**我们比 Noto 细 3px（约 12%），与 OPPO 最接近。**

这与设计意图一致：视觉等距减细，避免 Noto 偏重的问题。

## 二、国字的字面尺度

| 字体 | 字面宽 | 字面高 | 填充率 | 左右壁厚 |
|---|---|---|---|---|
| **我们** | **264** | 277 | 0.4424 | 23 / 24 |
| Noto | 266 | 280 | 0.5042 | 25 / 26 |
| OPPO | 253 | 276 | 0.4711 | 21 / 22 |
| 鸿蒙 | 260 | 280 | 0.5203 | 25 / 25 |

### 关键判断：只减细，没缩字面

如果「减细」实现方式不当，很容易连带**缩小字面**（整体缩放的副作用）。
实测证明没有：

| 对比维度 | 我们 vs Noto | 结论 |
|---|---|---|
| 字面宽 | 264 vs 266（−0.8%）| **几乎不变** |
| 字面高 | 277 vs 280（−1.1%）| **几乎不变** |
| 笔画厚 | 23 vs 26（**−11.5%**）| **显著变细** |

**笔画减了 11.5%，字面只小了 1%，这正是「只削笔画、不动骨架」的目标。**

如果当初用了整体缩放（比如 scale=0.985），
字面和笔画会同比例缩小，笔画只会细 1.5%，达不到设计意图。

## 三、填充率（墨量占比）

| 字体 | 填充率 | 相对我们 |
|---|---|---|
| **我们** | **0.4424** | — |
| OPPO | 0.4711 | +6.5% |
| Noto | 0.5042 | +14.0% |
| 鸿蒙 | 0.5203 | +17.6% |

我们**最轻**，鸿蒙最重。与 P45 的墨密度排序一致（OPPO 最淡 → 鸿蒙最重）。

## 四、视觉观察（大字号看图）

叠 100 单位网格看（图：docs/img/p52-big-ruler.png）：

1. **笔画端点**：我们的横画端口方正，与 Noto 一致，无圆角溢出
2. **转角**：国字四角方正，无外扩或内凹
3. **中宫**：「玉」部居中，与外框的间距四边均匀
4. **与 OPPO 对比**：我们的字面更宽（264 vs 253），读起来更舒展
5. **与鸿蒙对比**：鸿蒙最黑，大字号下笔画粘连感更强

## 五、结论

| 项 | 结果 |
|---|---|
| 横画厚度 | 23px（Noto 26 / OPPO 22），减细约 12% |
| 字面尺度 | 264×277（Noto 266×280），基本一致 |
| 减细方式 | **只削笔画，未缩骨架** ✓ |
| 填充率 | 0.4424，四款中最轻 |
| 端点/转角 | 方正，无缺陷 |

## 六、一个反直觉的验证点

「减细 12% 但字面只小 1%」听起来矛盾，实际正说明：

**厚度是沿笔画法向削的，不是整体等比缩放。**

这也是为什么不能偷懒用 `scale glyph` 做减细：
那样字体会变小，字间距会变松，整篇文字会显得松散。
