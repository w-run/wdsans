P17：去出脚算子实测验收 —— 5/5 完美生效

这是整个项目最成功的一项设计实现，数据与视觉双重确认。

## 一、视觉证据

`口日田目回国` @200px（docs/img/p17-feet.png，四款字体对比）：

- **Noto 基座**：每个方框底部的竖画都向下**伸出一截小腿**
- **鸿蒙 Sans**：出脚最明显，腿伸得最长
- **我们**：底边**完全平直，没有任何伸出**
- **OPPO Sans**：同样没有出脚

我们的处理与 OPPO 完全一致，与 Noto/鸿蒙明显区分。

## 二、量化验证

方法：渲染 400px，取字形底部 5% 高度带，计算「该带内的墨列数 / 字形总宽」。
- **无出脚** → 底部是整条底横 → 墨列占比 ≈ 1.000
- **有出脚** → 底部只有两条细腿 → 墨列占比 ≈ 0.2

| 字 | 我们 | Noto | OPPO | 鸿蒙 |
|---|---|---|---|---|
| 口 | **1.000** | 0.213 | **1.000** | 0.233 |
| 日 | **1.000** | 0.237 | **1.000** | 0.257 |
| 田 | **1.000** | 0.185 | **1.000** | 0.220 |
| 目 | **1.000** | 0.228 | **1.000** | 0.238 |
| 国 | **1.000** | 0.190 | **1.000** | 0.196 |

**5/5 全部与 OPPO 完全一致。**

## 三、拓扑检查

轮廓数与点数与 Noto **完全相同**（口 2轮/12点、日 3轮/16点、田 4轮/20点）：
```
我们  口 2轮/12点   日 3轮/16点
Noto  口 2轮/12点   日 3轮/16点
OPPO  口 2轮/ 8点   日 3轮/12点
```
说明我们的去脚是**几何位移**（把伸出段收回、与底横重合），
没有改变拓扑——完全符合 AGENTS.md 铁律「只移动节点，不增删节点」。

OPPO 点数更少（8/12 点）是因为它的端面设计更简洁（直切无过渡点），
不是我们的缺陷。
