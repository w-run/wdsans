# 笔末平切 — 第五轮：判据定稿（2026-11-19）

## 判据（最终版）

```
对每个 CJK 字形，遍历每个轮廓的每个段:
1. 轮廓 xmax > 700          （只看右侧撇/捺）
2. 段类型 = C 或 Q           （曲线端面，L 已是直线不用改）
3. 段长 40 <= L <= 160
4. 方向向上 dy > 0
5. |dx| >= 20               （已经足够垂直的不改）
6. |dx| <= |dy| * 0.85      （端面接近垂直，排除横笔斜切）
7. 前后段长度都 >= 100        （确保是端面，不是中间小段）
```

## 改法

```
端面段 C/Q  ->  垂直 L:
  new_end = (p0.x, e.y)

即保留终点的 y，把 x 对齐起点 x。

实测 大 轮廓1:
  原: [2] C (903,-77) -> (960,-8)    dx=57 dy=69
  改: [2] L (903,-77) -> (903,-8)    dx=0  dy=69
  OPPO 参考: L dx=0 dy=66
```

## 为什么选 0.85 而不是更严

```
核心撇捺字（大 人 天 夫 文 父）的 dx/dy 在 0.70~0.83:
  大 dx=57 dy=69 -> 0.83
  人 dx=55 dy=64 -> 0.86
  天 dx=53 dy=68 -> 0.78
  夫 dx=49 dy=70 -> 0.70

若限制 0.70，大字族会被漏掉。0.85 能覆盖核心字。
```

## 三次改法错误的记录

```

✅ new_end = (p0.x, e.y)              正确

第二个方案把长度算成 89（斜长），第三个算成 69（y 跨度），
```
