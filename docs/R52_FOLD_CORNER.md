# R49-R52 横折拐角修复历程（2026-11-19）

## 用户需求（逐步澄清）
```
1. 「要修横折拐角」
2. 「不是 SHS 的，是 OPPO 那种垂直过渡，斜边终点收进横线内」
3. 「400 字重的拐角基本没问题，就是目标的样子」
   「400 以上更重：横画有点长」
   「400 以下：斜画漏在外面很丑，应该收在横画轮廓内部」
4. 「R51 不合格，让斜边变粗了」
```

## 400 档目标几何（实测）
```
多 400:
  c1 斜边: start(734,752) -> L(719,752) -> C -> C -> C(770,685) -> close
  c2 横笔: (770,752)(385,752)(385,685)(770,685)

  横笔右上角 = (770,752)
  c1 起点    = (734,752)   dx = -36
  c1 末点    = (770,685)   = 横笔右下角（精确重合）
  close 线: (770,685) -> (734,752)  斜线
  斜边上端宽度 = 770 - 719 = 51
```

## ❌ R48 的错误：y 坐标跨档硬套
```
w250 实际 y=737 -> 被强制改成 752（上移15）
w900 实际 y=777 -> 被强制改成 752（下移25）
=> 只有 400 档正确，其余字重字形变形
用户反馈「400以上正常、400以下异常」正是这个原因
```

## ❌ R51 的错误：删回折段导致斜边变粗
```
R51 做法: 删除 c1 的 s0（回折段），start 对齐到 770
  结果: start(770,752) -> C(611,553)...
  斜边上边缘起点从 x=719 变成 x=770
  => 斜边上端加宽 51 单位 => 斜边明显变粗
用户反馈「R51 不太合格、让斜边变粗了」
```

## ✅ R52 正确方案（m_vertcorner3）
```
保留 s0（回折段），只移动 start 与对齐 y:
  1. c1.start.x = 横笔右端 x     -> close 线变垂直
  2. c1.start.y = 本档横笔上缘 y -> 修 1 单位错位
  3. c1.s0.y    = 本档横笔上缘 y -> 同上
  4. s0 的 x 保持原值            -> 斜边宽度不变

三档实测结果:
  w250  start(770,737) s0(736,737) 斜边宽34  close=VERT
  w400  start(770,752) s0(719,752) 斜边宽51  close=VERT
  w900  start(770,777) s0(691,777) 斜边宽79  close=VERT

斜边宽度 34/51/79 全部保持原值，不变粗。
三档 start.y 全部用本档值，不跨档。
```

## 🔴 两次都栽在同一个坑：绝对值跨档套用
```
R48: 套用了 400 档的 y 值 (752)
R52第一版: 索引里存了 400 档的 by1，三档都套用

规律: 索引只应存「哪个轮廓哪个点」和「x 目标」，
      凡是 y 相关的量必须在每个 master 内重新取。

实现要点: 三档应用时，用 bbox_of 在本档重新找横笔的 y_top，
          不能复用 400 档索引里的 y 值。
```
