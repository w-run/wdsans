# P46：笔画端点微观检查（锚点 on/off 比率）

## 为什么查这个

「笔画端点」决定了小字号下的锐利度：
- **全 on 点**（4 on / 0 off）= 纯直线矩形，端点方正
- **含 off 点** = 有曲线，端点是圆头或带弧

如果我们的直线笔画被误改成曲线（或反之），小字号会糊或过锐。

## 实测（on 点 / off 点 / 轮廓数）

| 字 | 我们 R | Noto | OPPO | 鸿蒙 |
|---|---|---|---|---|
| 一 | **4/0/1** | 4/0/1 | 4/0/1 | 4/0/1 |
| 丨 | **4/0/1** | 4/0/1 | 4/0/1 | 4/0/1 |
| 丿 | **6/11/1** | 6/11/1 | 6/8/1 | 6/6/1 |
| 丶 | **4/8/1** | 4/8/1 | 6/7/1 | 4/4/1 |
| 十 | **8/0/2** | 8/0/2 | 12/0/1 | 12/0/1 |
| 口 | **12/0/2** | 12/0/2 | 8/0/2 | 12/0/2 |

## 结论：六字全部与 Noto 逐项相同

| 观察 | 含义 |
|---|---|
| 一、丨 = 4 on / 0 off | 横竖笔画是**纯直线矩形**，端点方正，无多余曲线 |
| 十 = 8 on / 0 off / **2 轮廓** | 横竖是两个独立矩形（交叉处不合并），端点锐利 |
| 口 = 12 on / 0 off / **2 轮廓** | 内外双框，全直线 |
| 丿丶 = 含 off 点 | 撇点有曲线，与 Noto 的 off 点数完全一致 |

**没有任何一条笔画被误改。**

## 参照字体的差异（有趣但与我们无关）

| 字 | OPPO | 鸿蒙 | 差异说明 |
|---|---|---|---|
| 十 | 12/0/**1** | 12/0/**1** | 把横竖**合并成 1 个轮廓**（相交处熔接）|
| 口 | **8**/0/2 | 12/0/2 | OPPO 每个框只用 4 点而非 6 点 |
| 丿 | 6/**8**/1 | 6/**6**/1 | 曲线控制点更少（更简化）|

OPPO / 鸿蒙 采用了**不同的轮廓分解策略**（合并相交笔画、减少控制点）。
这是设计选择，不是优劣。

## 与 AGENTS.md 铁律的关系

AGENTS.md 第一条铁律：**只移动节点，不增删节点**。

本轮验证：一 / 丨 / 丿 / 丶 / 十 / 口 六个基础字的 on/off 点数
与 Noto **完全相同**，说明重构过程中**严格没有增删节点**。

这是对铁律的又一次独立确认。

## 方法说明

本检查用 `wds.contours.read_points()` 读取 on/off 标记，
不依赖渲染（因此不受 P43 的 woff2 问题影响）。
