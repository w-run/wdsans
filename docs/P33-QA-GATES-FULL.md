## 发现闸门自身的缺陷

### G5 对静态字体必然失败

```
G5 ERR Missing required table fvar
```

原因：`g5_structure` 无条件调用 `instancer.instantiateVariableFont`，
而静态实例**没有 fvar 表**，必然抛异常。

这不是字体问题，是**闸门脚本的设计缺陷**——它只为可变字体设计。

### 修法

```python
inst = TTFont(font_path)
if "fvar" in inst:                      # 静态实例跳过 instancer
    inst = instancer.instantiateVariableFont(inst, {"wght": wght}, ...)
gs = inst.getGlyphSet()
```
