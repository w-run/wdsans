# P51：VF（可变字体）交付验证

## 为什么查

我们发布了 `WDesignSansSC-VF.woff2`（20.01 MB），但**从未单独验证过它**。
此前所有行为测试都在静态实例上做。VF 是独立交付物，需要独立验证。

## 一、结构完整性

解包后 **22 张表**，关键表齐全：

```
BASE GDEF GPOS GSUB avar cmap fvar gvar glyf
head hhea hmtx HVAR loca maxp name OS/2 post STAT vhea vmtx
```

| 关键表 | 作用 | 状态 |
|---|---|---|
| `fvar` | 轴定义 | ✓ |
| `gvar` | 轮廓变化 | ✓ |
| `HVAR` | 宽度变化 | ✓ |
| `avar` | 轴值非线性映射 | ✓ |
| `STAT` | 样式属性（供系统识别字重）| ✓ |

## 二、轴定义

```
wght  min=250  default=400  max=900
```

| 项 | 值 | 判定 |
|---|---|---|
| 轴范围 | 250-900 | 覆盖 Thin..Heavy |
| **默认值** | **400 (Regular)** | 正确（Mona 原默认是 200，我们改成 400）|
| 轴数量 | 1（仅 wght，wdth 按要求锁 100）| ✓ |

## 三、7 个命名实例

| 实例名 | wght |
|---|---|
| Thin | 250 |
| Light | 300 |
| Normal | 350 |
| Regular | 400 |
| Medium | 500 |
| Bold | 700 |
| Heavy | 900 |

与 7 个静态实例**一一对应**。

## 四、avar 映射

```
wght: [(-1.0,-1.0), (-0.6667,-0.8519), (-0.3333,-0.2593),
       (0.0,0.0), (0.2,0.2787), (0.6,0.6394), (1.0,1.0)]
```

7 个映射节点，与 7 个命名实例对齐。

## 五、STAT

```
axes: [wght]
AxisValue 数: 7
```

`STAT` 决定**系统字体菜单里显示哪些样式**。7 个 AxisValue 对应 7 个字重，
Windows / macOS 的字重下拉框才能正确列出 Thin..Heavy。

## 六、中间字重插值（VF 的核心价值）

VF 的意义在于能取**任意** wght，不只 7 个固定档。用 12 个 wght 值渲染「永和九年」测墨密度：

| wght | 墨密度 | Δ | 单调 |
|---|---|---|---|
| 250 | 0.1556 | — | ✓ |
| 300 | 0.1703 | +0.0146 | ✓ |
| 350 | 0.2025 | +0.0323 | ✓ |
| 400 | 0.2230 | +0.0204 | ✓ |
| **425** | 0.2458 | +0.0228 | ✓ |
| **450** | 0.2638 | +0.0180 | ✓ |
| **475** | 0.2752 | +0.0114 | ✓ |
| 500 | 0.2815 | +0.0062 | ✓ |
| **600** | 0.3099 | +0.0284 | ✓ |
| 700 | 0.3397 | +0.0298 | ✓ |
| **800** | 0.3660 | +0.0262 | ✓ |
| 900 | 0.3966 | +0.0306 | ✓ |

**12 档全部单调递增，无异常跳变、无回退。**

加粗的 425/450/475/600/800 是**非命名档位**，只能由 VF 插值产生，
说明插值引擎工作正常。

### 一个观察：500-600 之间有个台阶

500→600 的 Δ 是 +0.0284，明显大于 475→500 的 +0.0114。
这与 P47 发现的 Noto 笔画非线性同源（Light→Normal 处跳变），
是基座设计特性，不是缺陷。

## 七、结论

| 项 | 结果 |
|---|---|
| 表结构 | 22 表齐全，含 fvar/gvar/HVAR/avar/STAT |
| 轴 | wght 250-900，默认 400 |
| 命名实例 | 7 个，与静态档一致 |
| avar | 7 节点 |
| STAT | 7 AxisValue |
| 中间插值 | 12 档全单调，非命名档位正常 |

**VF 可作为独立交付物发布。**

## 附：一个方法上的坑

直接 `TTFont(woff2).save(ttf)` 解包 **超过 2 分钟**（65k 字形全量重写）。
读 fvar/avar/STAT 这类小表**不需要 save**，直接 lazy 读即可。

测插值则用母版 TTF（`wdsans-FINAL.ttf`）实例化，
数据与 VF 相同，但速度快得多。
