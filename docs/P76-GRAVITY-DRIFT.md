# P76：七档重心漂移（字重变化时重心是否稳定）

## 上轮遗留

P75 只测了 Regular 一档的重心（175.3 vs 参照 178.1）。
但**重心可能随字重漂移**——粗体笔画加厚，重心会移动。

七档如果漂移过大，会显得「粗体版本的字往上/下跑」，破坏一致性。

## 一、我们的七档重心

| 档位 | wght | 平均重心 | 相对 Regular |
|---|---|---|---|
| Thin | 250 | 130.2 | −1.1 |
| Light | 300 | 130.3 | −0.9 |
| Normal | 350 | 131.1 | −0.2 |
| Regular | 400 | **131.3** | 0.0 |
| Medium | 500 | 132.5 | +1.2 |
| Bold | 700 | 134.0 | +2.7 |
| Heavy | 900 | 135.8 | +4.5 |

**严格单调上移**，跨度 **5.6 单位**（Thin 130.2 → Heavy 135.8）。

### 为什么会单调上移

粗体化时笔画整体加厚，但**上部横画（天、大、田的顶横）增幅更明显**：
- 汉字上部多为横画（水平方向延伸，加厚时面积增长快）
- 下部多为撇捺（斜向，加厚时增长相对慢）

净效果：上部墨量占比增加 → 重心上移。

**这是 CJK 字体粗体化的普遍现象，不是我们的问题。**

## 二、与 Noto 对比（决定性证据）

| 档位 | 我们 | Noto | 差 |
|---|---|---|---|
| Thin | 130.2 | 131.5 | −1.3 |
| Light | 130.3 | 131.7 | −1.4 |
| Normal | 131.1 | 132.9 | −1.8 |
| Regular | 131.3 | 133.4 | −2.1 |
| Medium | 132.5 | 134.7 | −2.2 |
| Bold | 134.0 | 136.5 | −2.5 |
| Heavy | 135.8 | 138.4 | −2.6 |

```
Noto  跨度: 6.9 (131.5 → 138.4)
我们  跨度: 5.6 (130.2 → 135.8)
```

### 三个观察

1. **趋势完全一致**：两者都是单调上移
2. **跨度同量级**：5.6 vs 6.9（我们的略小，因为减细压缩了差异）
3. **绝对位置略低**：各档低 1.3~2.6，与 P75 的 −2.8 结论一致

**我们的跨度更小（5.6 < 6.9）反而更好**——
意味着七档之间重心更稳定，粗体版本不会明显「往上跑」。

## 三、换算：仍属亚像素

```
最大跨度 5.6 / 300px 渲染 = 1.87% em
但这是「Thin 到 Heavy」的极端对比
相邻档位差通常 0.2~1.8 单位 = 0.07%~0.6% em

16px 字号下相邻档位差 < 0.1 px
```

实际排版中不会感知到档位间的重心跳动。

## 四、结论

| 项 | 结果 |
|---|---|
| 七档重心 | 严格单调，130.2 → 135.8 |
| 跨度 | 5.6 单位（Noto 6.9）|
| 方向 | **与 Noto 完全一致** |
| 绝对位置 | 各档低 1.3~2.6（与 P75 一致）|
| 是否缺陷 | **否**，是 CJK 粗体化的普遍现象 |
| 我们的优势 | 跨度比 Noto **小 19%**，档位间更稳定 |

## 五、教训

### 1. 单点测量要补成序列测量

P75 测了 Regular 一个点，得出「重心低 2.8」。
但真正的问题是「**七档是否一致**」——这是单点测不出来的。

**测趋势比测单点更有价值。**

### 2. 「我们的跨度更小」是个意外的好消息

预期是「减细可能导致重心漂移异常」。
实测发现跨度 5.6 < Noto 6.9——**减细反而让档位间更稳定**。

因为减细是固定偏移（P53），对粗体减得相对少，
客观上压缩了粗细档之间的墨量差异，连带压缩了重心漂移。

**同一个机制（固定偏移减细）在不同指标上产生了不同效果**：
- 笔画厚度：造成非线性（P53）
- 重心漂移：反而更稳定（本轮）

### 3. 与参照对比仍是判断「正常还是异常」的唯一可靠方式

如果只看我们自己的 5.6 跨度，无法判断这是大还是小。

对比 Noto 的 6.9 之后立刻清楚：**同量级，且我们更优**。

这是 METHOD-TRAPS 里「对比参照」原则的又一次应用。
