# P35：VF WOFF2 漏更新（Latin Ext-A 仍是旧版）

## 缺陷

P30 修复 Latin Ext-A 后，`deliver2` 重建了七档静态产物，
**但 VF WOFF2 没有被重建**——它还是 14:29 的旧文件。

实测：

| 文件 | 时间戳 | cmap | Latin Ext-A |
|---|---|---|---|
| 七档 TTF | 19:57–20:27 | 44,905 | **125/128** |
| 七档 WOFF2 | 20:01–20:31 | 44,905 | 125/128 |
| **VF WOFF2** | **14:29** | **44,810** | **30/128** ← 旧版 |

## 为什么漏了

`deliver2.build()` 的流程是：
```
for 每个标称档位:
    instancer 出静态 TTF  ->  hb_advances 修 advance  ->  meta_fix
    再转 woff2
VF woff2  <-  单独的另一个分支（不在上面的循环里）
```

VF 的 woff2 是早期手工生成一次后就没再进管线。
P30 改了母版，静态档全部走管线重建，VF 不在管线里，于是漏掉。

## 修复

直接从修好的母版重新转 woff2：
```python
f = TTFont("/data/build-cache/wdsans-p1/wdsans-FINAL.ttf")
f.flavor = "woff2"
f.save("WDesignSansSC-VF.woff2")
```

生成耗时约 4 分钟（20MB woff2 压缩很慢）。

## 验证

| 项 | 修复前 | 修复后 |
|---|---|---|
| cmap | 44,810 | **44,905** |
| Latin Ext-A | 30/128 | **125/128** |
| fvar | 有 | 有（可变性保留）|
| 大小 | 20.04 MB | 20.01 MB |
| 已同步 w-pc | 否 | **是**（字节数一致）|

## 教训

**「重建全部产物」这句话必须逐项核对，不能只看主要产物。**

我在 P31 声称「七档全部重建完成」，这是对的；
但没意识到「VF WOFF2」也是交付物之一，它不在那个「七档」里。

这与 P30 的 gvar 遗漏同类：**验证覆盖面有个默认的认知边界，
边界外的东西不会被想起来检查。**

以后交付前应该跑一个「产物清单 vs 母版时间戳」的自动核对，
而不是靠记忆确认哪些重建了。
