# 笔末平切 — 第四轮：方案确定并验证通过（2026-11-19）

## 成功方案：端面段改成「垂直 L」

### 判据（严格）
```
对每个 CJK 字形:
1. 只看 xmax > 700 的轮廓（右侧撇/捺）
2. 找短段: 40 <= L <= 160
3. 方向向上: dy > 0
4. 前后段都是长段: >= 100
5. 段类型为 C 或 Q（曲线端面）
```

### 改法（关键，走过三次错误）
```
❌ 错误 1: new_end = (e.x, p0.y + L)   -> dx 不变，端面不垂直
❌ 错误 2: new_end = (p0.x, p0.y + |e.y-p0.y|)  -> 长度对但起点错
✅ 正确:   new_end = (p0.x, e.y)

含义: 保持终点的 y，把 x 对齐起点的 x。
      即端面变成从 (p0.x, p0.y) 到 (p0.x, e.y) 的垂直线段。
```

### 实测数据
```
大 轮廓1 (原版 LCCC -> 改后 LCLC):
  [1] C: (476,504) -> (903,-77)     下边缘长曲线（不动）
  [2] C: (903,-77) -> (960,-8)      端面段
      -> 改成 L: (903,-77) -> (903,-8)   dx=0 dy=69
  [3] C: (960,-8) -> (550,522)      上边缘回（不动）

OPPO 参考: L dx=0 dy=66   <- 长度 69 vs 66，匹配良好
```

### 目视确认

6 个字（大 人 天 夫 文 父）在原版/改后/OPPO 三联对比中:
- 原版: 捺末端圆弧收尾
- 改后: 明确的垂直平切面，与 OPPO 形态一致
- 未出现「方头」问题（上一轮的失败模式）

## 与上一轮失败方案的对比
```
上一轮: C -> L 用原段长度（斜长 89）
  -> 凸包比 1.010（改善）但目视变方头、末端偏厚

本轮: C -> 垂直 L（长度 69，取 y 跨度）
  -> 凸包比 0.995（更接近 OPPO），目视形态自然

差异根源: 端面必须是「垂直」的（dx=0），而上一轮的 L 是斜向的。
```
