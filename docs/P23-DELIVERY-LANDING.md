## 一、全字库扫描（详见 P22）

扫描 1614 个汉字，验证是否存在系统性缺陷。结论：**没有**。

| 指标 | 结果 |
|---|---|
| 包围盒宽度比（我们/Noto）| p50=0.9895，**偏离 >1% 的字数 = 0/1614** |
| 包围盒高度比 | p50=0.9859，p5~p95 = 0.9823~0.9887 |
| 减细比 vs 笔画密度 | **r = 0.088**（无相关），五档均 0.801~0.810 |

整个字库经过同一个均匀变换，无局部破坏。

### 推翻自己的一个假设

先做「墨量比」扫描时，离群榜全是氵/糹/髟部字（比值 0.59~0.76），
一度判断「偏旁字被过度减细」。实测推翻：
- 密度相关性 r=0.088，减细均匀
- 包围盒 0 离群，无局部缩放
- 轮廓数与 Noto 逐一相同（漆 14轮/143点、鬖 24轮/294点）
- 目视：氵的三点粗细相当

真实原因是「墨量比」这个指标对笔画分布过敏——
氵这类「多短笔画+大留白」部件天生墨量低。**是指标缺陷，不是产品缺陷。**
