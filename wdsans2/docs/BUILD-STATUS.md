## VF 构建的硬性约束（血泪教训）

1. **三档段数必须相同** → 用 400 档检测、按索引传给三档
2. **每个点的操作符类型也必须相同** → 替换端面时保持原类型（C→退化三次曲线，L→直线）
   - 违反实例：`uni3495` c8 在 400 档变 L 而其他档是 C → varLib.build 报错
3. **切面位置必须按比例而非绝对值** → cutp 用两端投影中点
4. **应用阶段绝不能再做尺寸过滤** → 否则小字重会被全部拒绝
