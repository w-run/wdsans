## 三、关键技术教训

### 3.1 平切算法：不能用切面截断

**错误做法**（flatcut_xw.py，已废弃）：
```
切面 cutp=(a@dv+b@dv)/2，用 de Casteljau 把相邻段截断到切面
问题：dv=d1-d2 在两条边方向差异大时严重偏斜
后果：多 bbox y[-82,840] → y[-9,809]，整条笔画消失
```

**正确做法**（flatcap2.py）：
```
只识别「短端面段」（0.25~1.3×笔画宽，前后接长边）
把该段换成同端点直线
端点不动 → bbox 天然不变
安全阀：bbox 变化 > 0.55×笔画宽则跳过
验证：26 字 bbox 变化全部 [+0 +0 +0 +0]
```

### 3.2 折角不是问题

- SHS rmin=8.1，OPPO rmin=8.3，**差异仅 1.7%**
- 早期误判「SHS 折角硬」是错的
- 真正的视觉差异来自**台阶凸起**（两段短直线拼直角），不是曲率

### 3.3 VF 构建三条硬约束

1. **三档段数必须相同** → 400 档检测、索引传给三档
2. **每个点的操作符类型必须相同** → 替换时 C 用退化三次曲线，L 保持直线；删除段改为零长度退化段（不真删）
3. **位置参数按比例非绝对** → 索引驱动，不用各档自身阈值

违反后果：`VarLibCFFPointTypeMergeError`
