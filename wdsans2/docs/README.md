## 已实现的改造

### 去出脚（857 字）

SHS 框结构底部有竖线突出，OPPO/HOS 没有。

判据：轮廓底部的「竖-短横-竖」U 形凸起
- 横边长 0.35–1.8×笔画宽
- 横边在字底部 1.0×笔画宽内
- 前后各接竖边，竖边向上延伸到轮廓顶
- 黑名单排除单竖笔收笔（王生川中申甲十用主玉土干工丰士卅三）

高度补偿（按用户规则）：
```
1. 出脚点抬到参照横边 y       （去出脚）
2. 框轮廓下移 delta           （拉低两侧竖线）
3. 底横轮廓下移 delta         （拉低本体横线）
4. 内部内容下移 delta/2       （保持垂直居中）
```

验证：口/田/国/回/四/凹 的 bbox 高度与 OPPO 误差 **0 unit**

### 拉丁 Mona Sans（347 字）

- ASCII + Latin-1 + Latin ExtA 中 SHS 已有的 238 个码位：替换轮廓
- Latin ExtA 中 SHS 缺失的 **109 个码位**：复用空闲字形槽位新增
- 复合字形（Ą/Ć/Ę/Ń/Ź…）用递归展开 `addComponent` 处理

## 关键技术

### CFF2 多变体一致性

所有 master 的 charstring 操作符序列必须完全相同。
用 **CanonicalPen**：只输出 `rmoveto`/`rlineto`/`rrcurveto`，
二次曲线转三次，不追加闭合段。

### qCurveTo 多点

TrueType 二次曲线 N 点 = N-1 控制点 + 1 终点，
相邻控制点中点是隐含 on-curve 点。逐段处理会把曲线拉成折线。

### 复合字形展开

`RecordingPen` 对 composite 只记录 `addComponent(name, matrix)`。
需递归展开并级联矩阵乘法：
```
comb = (a·ta+c·tb, b·ta+d·tb, a·tc+c·td, b·tc+d·td, a·te+c·tf+e, b·te+d·tf+f)
```

### 65,535 字形上限

CFF2 glyphID 上限 65,535。SHS 已满。
解法：复用未映射且未被 GSUB 引用的空闲槽位（11,840 个可用）。

### post 表

65,535 字形超过 post 2.0 索引上限，强制 `formatType=3.0`。

## 方法论：光栅化 > 几何

同一指标（中宫）的五次尝试：

| 方法 | SHS | OPPO | 判定 |
|---|---|---|---|
| 轮廓面积比 | 0.285 | 0.682 | ✗ 结构不可比 |
| pathops 墨量/bbox | 0.531 | 0.510 | ✗ 结论反转 |
| 孔洞绕向比 | 0.000 | 1.639 | ✗ 记法不兼容 |
| flood-fill 内白率 | 0.243 | 0.303 | ⚠ 受拓扑影响 |
| **墨量占比** | — | — | ✓ 与拓扑无关 |

根因：SHS 用「同向重叠轮廓 + nonzero」，OPPO/HOS 用「反向真孔洞」，
拓扑层面不可直接比较。

```
IoU 只从 0.7106 提升到 0.7112 (+0.0005)
时 0.635→0.626  明 0.564→0.562  吗 0.624→0.618  全部变差
```
