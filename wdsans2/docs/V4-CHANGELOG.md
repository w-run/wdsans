# WDesign Sans · v4 变更记录

> 2026-11-12 · 从 v3(去出脚857字) 到 v4(去出脚1791-1833字)

## 一、本轮突破：双判据 + 偏旁出脚

### 判据从 1 个扩展到 2 个

```
判据A (U形凸起): 轮廓底部的「竖-短横-竖」结构
  适用: 口 日 田 国 白 目 百 回 四 品 晶 凸 凹 吕 古 石 右 础
  处理: 出脚点抬到参照横边 y + 整体下移补偿

判据B (细长竖条): 宽<1.6*sw 高>2.5*sw 的简单矩形竖条
  适用: 时 明 吗 阿 啊 俺 岸 (偏旁的单侧出脚)
  处理: 竖条底端抬到相邻长横边 y（不下移）
```

### 关键修复：字段不匹配

`footfix2.find_ref_local` 期望 `foot['h']`，但 `feet4` 用 `foot['ci']/foot['k']`，导致 `except Exception: pass` 静默吞掉所有 U 形处理，只有竖条生效。
修复后处理率 **32% -> 74%**。

### 覆盖提升

```
v3 (m14):  manifest 1677 字, 实际处理 857 字
v4 (m16):  manifest 2464 字, 实际处理 1833/1791/1797 字 (250/400/900)
           覆盖率 51% -> 73%
```
