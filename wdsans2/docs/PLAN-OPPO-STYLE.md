# WDesign Sans · OPPO 风格改造计划


## 许可约束（决定技术路线的前提）

**事实**：OPPO Sans / HarmonyOS Sans / MiSans 均**禁止二次开发**（不可派生、不可修改再发布）。
思源黑体（Source Han Sans）采用 SIL OFL 1.1，**允许自由修改与派生**。

**因此本项目只能**：
| 允许 | 禁止 |
|---|---|
| 用 OPPO/HOS/MiSans 作为**视觉参考**、测量其几何特征 | 从这些字体**采样轮廓**、复制曲线、做布尔融合 |
| 把测量得到的**统计规律**转成规则，作用在 SHS 上 | 把它们的字形数据写进产物 |

**规模约束**：同量级（44,853 cps / 65,535 glyphs）且协议宽松的字体，
目前只有 SHS。这是选择 SHS 作为基底的**唯一充分理由**——不是风格更接近。

**对方案的直接影响**：
- Plan B（SDF 融合 OPPO）**不可行** —— 它实质是复制 OPPO 的轮廓信息
- 只能走 **Plan C（测量→规则→作用于 SHS）**
- 目标不是"像 OPPO"，而是"去掉 SHS 自身不该有的装饰（锐角/斜切/双尖）"
