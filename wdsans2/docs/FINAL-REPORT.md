## 五、关键技术结论

### 5.1 VF 构建三条硬约束（必须遵守）

1. **三档段数必须相同** → 400 档检测、索引传给三档
2. **每个点的操作符类型必须相同** → C 用退化三次曲线，L 保持直线；删除段改为零长度退化段
3. **位置参数按比例非绝对** → 索引驱动

违反后果：`VarLibCFFPointTypeMergeError`

### 5.2 平切算法演进

**失败**（flatcut_xw.py）：切面截断几何
→ `多` bbox y[-82,840] → y[-9,809]，整条笔画消失

**成功**（flatcap2.py）：只拉直已有端面，端点不动
→ 26 字 bbox 变化全部 [+0 +0 +0 +0]

### 5.3 折角不是问题

量化结果：SHS rmin=8.1，OPPO rmin=8.3，**差异 1.7%**
早期误判「SHS 折角硬」是错的。真正的视觉差异来自**台阶凸起**。

### 5.4 部首检测白带判据

真左偏旁与右部件之间有清晰白带 → 右缘处墨水占比 ≤ 0.18
误判字（口/日被外框包住）→ ≥ 0.23

实测完美分离，剔除 118 字误判。

三次判断被实测推翻：
