# WDesign Sans

**中文黑体 · 无限字重 · 一套统一**

以开源黑体为骨架，按国内主流手机系统字体的比例重做：横竖等粗、折角归正、撇捺收锋。
20,992 个汉字与拉丁共用同一套笔干粗细，中英混排不断裂。

## 六个数字

不靠眼睛估，六项指标量到小数点后三位，逐项对齐主流手机系统字体。

| 指标 | 数值 | 说明 |
|---|---|---|
| 重心（墨质心） | 0.499 | 笔画排布落在字面正中略偏上 |
| 中宫（墨密度） | 43.2% | 中宫收紧，字形不散 |
| 字面比例 宽/高 | 915 / 911 | 与汉字字面框协调 |
| 撇捺展开 60/70/80% | 0.524 / 0.535 / 0.610 | 下半区展开幅度 |
| 折角（纯直线段） | 90.0° | 几何上的真直角 |
| 笔画等粗 横/竖 | 0.951 | 横 77 / 竖 81 em，两向等粗 |

## 笔画

黑体的性格全在起收与转折：

- **端面** 笔末端面一律垂直于笔画方向，不做斜切、不留斜角
- **折角** 转折处精确 90°，内外角都是直角
- **收锋** 撇捺由根到尾自然收细，尾端留一点平口

「永」拆成八段看：点、横、竖、钩、提、撇、捺、短横——每一处都统一。

所有闭合部首的轮廓首末点做了对齐，全库 20,992 字无残留缝隙，
放大到海报级字号也不出现台阶。

## 尚未实现

- **顶横出头** 顶部横笔右端延伸。三轮自动判据（几何轮廓法）均误伤左侧偏旁的横笔，
  最大一次误伤 1,456 字，已放弃自动方案。当前继承思源黑体的原始形态。
  若重做需建立部件级分割，或改为逐字白名单。

## 字重

可变字重是一条连续的轴，`wght` 250–900。9 个命名实例只是刻度：

| 数值 | 名称 | 中文 |
|---|---|---|
| 250 | ExtraLight | 极细 |
| 300 | Light | 细 |
| 350 | Normal | 准 |
| 400 | Regular | 常规 |
| 500 | Medium | 中 |
| 600 | SemiBold | 中粗 |
| 700 | Bold | 粗 |
| 800 | ExtraBold | 特粗 |
| 900 | Heavy | 黑 |

中间任意数值都成立，例如 437、512 都能直接用。

## OpenType 特性

时间冒号居中 `calt` · 比例数字 `pnum` · 分数 `frac` · 上标 `sups` · 下标 `subs` ·
科学上下标 `sinf` · 分子分母 `numr` `dnom` · 连字 `liga` `dlig` · 竖排 `vert` `vrt2`

数字特性在中文环境下同样生效。

## 文件

| 文件 | 说明 |
|---|---|
| `WDesignSans-VF.otf` | 可变字体，wght 250–900（41 MB） |
| `WDesignSans-FlatApex-Regular.otf` | 静态 400，含顶点平顶（18 MB） |

两个版本并存：日常用可变版，需要平顶风格时用静态版。

> 顶点平顶需要改变字形拓扑，与多档可变字体的插值不兼容，因此单独提供静态版本。
